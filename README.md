# ΞΦΩ | XiPhiOmega

Independent architectures. Shared invariants. Verifiable discovery.

An experimental interoperability laboratory proposed by PHI369 Labs. The name references three independently developed research directions: [Xi](https://github.com/rookslackie), [Phi](https://github.com/MichaelWave369), and [Omega](https://github.com/medicinalElJefe). This repository does not imply endorsement, membership, shared ownership or agreement by the other maintainers.

## XPO-001: conservation and continuity

A deliberately narrow, dependency-free reference experiment for exact scalar exchange on a finite rational grid. It is not a neural model, production runtime, distributed transaction protocol or implementation of Tessera, Altermath or Dewey Calculus.

Run with Node.js 20+:

```sh
node tests/conformance.mjs
```

See [protocol](docs/XPO-001.md) and [source research map](docs/RESEARCH_MAP.md). Original reference code is covered by this repository's existing MIT license; upstream code and assets are not included or relicensed.

## XPO-002: canonical capsule transport

Independent JavaScript and Python binary codecs, strict UTF-8, namespace separation and bounded decoding. Run `node tests/capsule-conformance.mjs` with Node 20+ and Python 3.10+. See [wire contract](docs/XPO-002.md). Transport is not authorization or upstream compatibility.

## XPO-003: recursive addresses and identity

Exact, bounded base-20,736 paths, independent namespaces and address kinds, decimal-string ordinals and separate identity locators. Node/Python conformance: `node tests/address-conformance.mjs`. See [address contract](docs/XPO-003.md). Addressability is not allocated state, topology or authority.

## XPO-004: typed semantic adapters

Synthetic versioned dialect registry, exact rational unit conversions, strict meaning checks and unknown-value preservation. Run `node tests/semantic-conformance.mjs` (Node/Python). See [semantic membrane](docs/XPO-004.md). These invented dialects are not native upstream adapters.

## XPO-005: historical replay and reconstruction

Bounded exact exchange journal, singular-transition scar witness, historical snapshots, hash-linked receipts and independently checked replay. Run `node tests/journal-conformance.mjs` (Node/Python). See [continuity contract](docs/XPO-005.md). Hashes and an optional externally supplied tip are not authentication or durable storage.

## XPO-006: independent execution and authority

Scoped Ed25519 permits for a single synthetic journal gate, revision/tip binding, expiry, duplicate nonce refusal and independent final replay. Run `node tests/authority-conformance.mjs` (Node/Python). See [authority contract](docs/XPO-006.md). No durable replay protection or production authority.

## Research ladder

1. Exact scalar exchange
2. Canonical transport and bounded decoding
3. Namespace and recursive address contracts
4. Typed semantic adapters
5. Historical replay and reconstruction witnesses
6. Independent execution and authority boundaries
7. Matched-budget topology benchmarks
8. Cross-runtime conformance with consenting maintainers
9. Integrated demonstration with independent verification

The first six reference experiments are supplied here. Subsequent stages remain proposed research directions.
