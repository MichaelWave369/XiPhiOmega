# XPO-002 v1 — canonical capsule transport

Status: experimental, transport only, authority NONE. Original independent wire format; not Tessera, Altermath, or OMEGA compatibility.

## Wire contract

All lengths are byte lengths. In order: ASCII magic XPO2 (4 bytes), namespace (u16 big-endian byte length + UTF-8), operation (same), atom count (u8), each atom (u16 big-endian length + UTF-8), SHA-256 of all preceding bytes (32 raw bytes). No trailing bytes. Namespace and operation each match ASCII [a-z][a-z0-9.-]{0,63}; zero to 16 atoms, each zero to 1024 UTF-8 bytes. Maximum accepted frame 16,600 bytes. Strict UTF-8, no Unicode normalization, no replacement of malformed sequences. Preserve combining marks, BOM as data, NUL, empty atoms and arbitrary Unicode scalar values. Reject surrogate code points, unsupported magic, unknown object fields, bad lengths, invalid witnesses and noncanonical representations. This is framing, not compression. A namespace label is not an authenticated identity; unknown operation names may be transported but are never executed.

The digest detects accidental mutation and is a reproducibility witness, not authentication: anyone can recompute it. No remote input service, signatures, execution authority, semantic mapping, replay or resource claims beyond these bounded codec operations. JSON used by the test harness is not the wire format. Test-only Python bridge assumes trusted local fixture input.

## Conformance

Node 20+ and Python 3.10+, no dependencies. Run node tests/capsule-conformance.mjs from root. It checks 373 valid vectors (369 generated plus four explicit), exact byte parity between independently written implementations, decoded structure and re-encoding, namespace and Unicode distinction, and refusal of malformed objects and frames. Includes maximum-length fields/atoms and one-bit mutation at every byte of one representative frame. Not exhaustive over all Unicode or attack inputs. XPO-001 remains separate.

Future: agreed adapters, scoped authority, exact address semantics and independently reviewed execution. No third-party source included.
