# XPO-007 v1 — matched-budget topology study

Status: synthetic numerical graph experiment, authority NONE. Not a native Xi/Phi/Omega runtime or measured network performance. All graphs have 144 nodes, 288 undirected simple edges, degree four, connected; identical synchronous conservative scalar diffusion with alpha=1/8, 36 sweeps (10,368 edge updates per task). Each edge update exchanges equal/opposite delta from the previous sweep. Compare final disagreement relative to initial L2 disagreement (RMS across tasks), worst case, per-family RMS and absolute sum drift. Values in [0,1]. All workloads share the same vertex labels.

## Frozen design

Fixed circulants with strides 2,12,13,33 (each plus ring +/-1); a 12x12 periodic grid; a random degree-preserving rewired stride-12 graph (369 proposal attempts); an adaptive degree-preserving rewired stride-12 graph (72 proposal attempts, greedily accepts improvement in mean squared relative disagreement on nine training tasks). Invalid or disconnecting swaps refused. Separate deterministic xorshift seeds for training (0x12345678), holdout (0x9abcdef0), random rewiring (0x13579bdf), adaptive rewiring (0x2468ace1). Workloads alternate impulse, contiguous 12-node block and binary pattern. Nine training tasks, 36 held-out tasks (12 each family). No holdout score used for training. Candidate selection has extra search cost; report it explicitly. Fixed/random baselines are not given equal search budgets, so compare matched evaluation work only, not optimizer superiority. Stride33 was selected from prior exploration, not a blind baseline.

Wire proxy = sum of circular label distances min(|a-b|,144-|a-b|) over edges. No physical link geometry measured; same edge-update count does not guarantee same latency, bandwidth or energy. No wire penalty in training objective. Training/holdout distributions are narrow and correlated by generator design; only one graph seed per random/adaptive variant. No universal topology claim, no claim of a full mycelium, no causality or semantic averaging. Diffusion applies only to compatible scalar channels.
