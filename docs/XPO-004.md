The same glyph can denote three different concepts. Only exact dialect/version/symbol/unit bindings are valid. Never guess from glyph shape, dimension, proximity or unknown names. Translations require identical registered concept, not merely equal numeric values. There are no automatic aliases, fuzzy matches, Unicode normalization or registry mutations. Names are not authenticated.

Records have exactly dialect, symbol, unit, status, value. Targets have exactly dialect, symbol, unit. Units: length m/cm/mm, duration s/ms, resource 1. Unit conversion uses exact integer factors relative to the canonical unit (m, s, 1). Known values are canonical reduced rational strings n/d, signed numerator, positive denominator, at most 36 digits each. Unknown is status unknown with null value; never converted to zero. No other missingness classes are represented. Negative values are allowed as synthetic mathematical quantities; this does not grant physical admissibility. Refuse unsupported versions, meanings, units, noncanonical values, overflow of the output digit budget and malformed records.

For supported source and target, x' = x * targetScale/sourceScale. The independent Python Fraction implementation and JS BigInt implementation must agree exactly. If translation and reverse both fit the bounded domain, original record reconstruction is exact.
