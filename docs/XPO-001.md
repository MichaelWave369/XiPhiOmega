# XPO-001 v1 (draft)

Status: SYNTHETIC / authority NONE. Reference only. No external effects. No upstream compatibility claim.

## Domain and math

Inputs a,b,w are integers 0 through 12 representing fractions over 12. Exchange returns integer numerators over 288: a'=24a+w(b-a), b'=24b-w(b-a). Conservation holds exactly and outputs remain in [0,1]. For w=12 the transformation is singular; the original difference must be retained separately to reconstruct the input. The receipt records both inputs. All 2197 triples are tested, including 2028 nonsingular and 169 singular cases. No floating point tolerance is needed in this finite domain.

## Request

Exact keys: schema="xpo.001.v1", id (lowercase ASCII identifier), operation="exchange.synthetic", weight (grid integer), a="pocket-a", b="pocket-b", expectedRevision (nonnegative safe integer below MAX_SAFE_INTEGER). State is a trusted synthetic fixture with exact keys revision,a,b,used. Null is unknown, never zero. The reference rejects unknown operations, invalid types, stale revisions and duplicate IDs in the supplied replay set. The replay set is bounded to 128 entries; capacity exhaustion refuses.

The reference is a pure single-step function, not a database or transaction system. It returns a candidate receipt, incremented revision and proposed next replay list, but does not commit state. A receiving runtime must implement atomic commit, durable replay and concurrency protection separately. Outputs are on a finer grid than inputs; general chained exchange is not defined by v1. Request identity, caller authority, signatures, canonical byte encoding and untrusted JSON parsing are out of scope. Do not use the reference to authorize actions.

## Conformance

Compare exact numerators, denominator, invariant residual, original inputs and revision. Test independently before any adapter is marked compatible. Negative tests must not mutate the input fixture. The protocol can be implemented without copying upstream source. Future changes require explicit version negotiation and agreed semantics.
