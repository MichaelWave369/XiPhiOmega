# XPO-005 v1 — continuity journal

Status SYNTHETIC / authority NONE. Original offline pure reference, not a native Xi/Phi/Omega adapter, production persistence or proof of external execution.

## Exact repeated exchange

Two fixed fixture identities xpo-id/phi/pocket-a and pocket-b. Initial a,b are integers 0..12 over denominator 12. For every integer coupling w in 0..12, compute delta=w*(b-a), next numerators 24*a+delta and 24*b-delta, next denominator 24*d. Numerators and denominator are decimal strings, not floating-point. The denominator is deliberately unreduced and determined by revision. State is nonnegative and each scalar is at most 1; combined rational value conserved. This extends XPO-001 only for this finite, bounded journal.

At w=12 the next difference is zero. Record the original signed difference numerator as a scar at the input denominator, plus the full prior state. Reconstruct the historical inputs by replaying the recorded genesis and operations, not by inverting a singular output.

## Canonical journal

Compact ASCII JSON arrays only. Genesis = ["xpo5.v1","synthetic","none","xpo-id/phi/pocket-a","xpo-id/phi/pocket-b",a,b]. Root tip = SHA-256 of compact JSON ["xpo5.genesis.v1",genesis]. Envelope = [genesis,events]. Each event = [id,expectedRevision,weight,previousTip,before,after,scar,digest]. Before/after = [numeratorA,numeratorB,denominator] strings. Scar null except w=12. Digest = SHA-256 of compact JSON ["xpo5.event.v1",first seven event fields]. All digest strings lowercase hex. IDs follow ASCII [a-z][a-z0-9.-]{0,63}, unique within a journal. Revisions start at 0 and advance one per event. Reject noncanonical JSON, stale requests, duplicates, extra fields, malformed events and mismatched recomputed results. Maximum 36 events, 65,536 ASCII bytes. Append is a pure function taking a canonical journal and request {id,weight,expectedRevision,expectedTip}; returns a new journal without committing any external state. atRevision reconstructs a historical state after verifying the full journal.

## Integrity boundaries

Replay independently regenerates every state, scar and digest from genesis and operations; a matching hash alone is insufficient. A supplied expectedTip must match the reconstructed tip, detecting truncation or divergence relative to that trusted external value. A shorter internally consistent history otherwise remains valid. No external anchor is supplied by this library. A party can rewrite a whole valid journal and compute new hashes; this is not authentication, signature verification, physical observation, durable replay protection, transactional storage or concurrency control. No execution authority or external state changes. Test harness assumes trusted local fixture JSON.
